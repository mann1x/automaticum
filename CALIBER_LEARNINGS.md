- **[pattern]** A per-batch or per-run option that is not part of the arm (capture, limits, held-out, seeds) follows one path. It goes in `StartRequest` and `StartResponse` in `internal/daemon/api.go`, including the condition that decides whether the control file is saved at start. - **[gotcha]** A multi-file edit written as one Python script with `assert old in s` per replacement writes the files before the failing assert and skips the rest. After an `AssertionError`, run `git diff --stat` on the target files to see which ones were written, and rerun only the missing ones. A common cause is an earlier `replace` in the same script that changed the text a later anchor needed. Python edits also bypass gofmt: adding a short field name to an aligned Go struct leaves it misformatted. Run `gofmt -l internal/ cmd/` after such edits and `gofmt -w` the files it lists.
