The task loader is used from other packages' tests too: a signature change to `task.Find`/`task.LoadAll` also touches `internal/gate/gate_test.go` and `internal/run/run_test.go` (find them with `grep -rn 'task.Find(\|task.LoadAll(' --include=*_test.go internal cmd`), and the loader must stay valid under `go vet ./internal/task/` before `go test -short`.
- **[gotcha]** The private tasks root (D105, `private_tasks` in the local configuration's `[daemon]`) is read by the daemon beside the repository's `tasks/`, but the CLI's `task ls`, `task show`, `task build`, `oracle verify` and `cell run` only see it when `AUTOMATICUM_CONFIG` names the config directory; without it they read the repository's `tasks/` alone and a private task looks missing. Every task there must say `private = true` with a `canary` of 16 characters or more, and the same `<suite>/<task>` in both roots is a load error for the whole set, so a private task can never shadow a public one.
