- **[gotcha]** Source and spec edits made with an inline `python3 - <<'EOF' ... s.replace(old, new)` do nothing, without an error, when the anchor text does not match. Print `echo "script exit $?"` directly after the script, treat a missing status file as a failure, and read the task's own output file for the error. The broken wrapper had been derived from the working one with `sed 's#^DATA=...#'`, which replaced a whole line that also set other variables: derive a variant with the asserted `python3` replacement of only the wanted assignment, then check it with `bash -n <script>` and a `grep -c` for the variables it must still set before running it.
- **[gotcha]** A field the runner writes on its `end` line reaches `provenance.runner` in `automaticum run show <id> --json` only when the end-line struct in `internal/run/protocol.go` declares it: `iterations` and `questions_answered` were on the line in `logs <id> --events` but came out as `None` in the run record until the struct had them. When a runner field is added or a value in the record is unexpectedly empty, compare the keys of the last line of `logs <id> --events` with that struct, then run `gofmt -l internal/run` and `go vet ./internal/run/`.
