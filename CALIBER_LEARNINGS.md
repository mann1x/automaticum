- **[gotcha]** xOllama's `/api/show` lists a tag's parameters in an order that changes between releases, even when the values are the same. Never hash or compare the raw text. Use `run.ParametersKey`, which sorts the lines. Otherwise `compare` shows `CHANGED BETWEEN RUNS` for `tag parameters`, and the before/after probe can make a run `INVALID`.
- **[pattern]** Compare runs with `automaticum compare <batch> [<batch> ...]`. Use `--all` for every metric and `--json` for the numbers. It needs the running daemon on the current build. A batch started with `--idempotency-key <key>` is named `k-<key>`. Queue several arms as one interleaved batch with `run start --arm A --arm B --task <suite>/<task> -n <n>`, and check it with `--dry-run` first. `automaticum basis diff <batch[/arm]> <batch[/arm]>` lists exactly the 020 §5 facts that differ. `basis show <batch> [--arm A]` marks `MIXED` where the runs of one group differ.
- **[convention]** A new command in `cmd/automaticum` is one entry in the `cmds` map of `main.go` under `"<noun> <verb>"`, plus one line of usage. One-word commands go in the `one` map. Parse flags with `args = parse(fs, args)`, not `fs.Parse(args)`, because Go's `flag` stops at the first argument that is not a flag. Run `grep -n '^func <name>' cmd/automaticum/*.go` before you add a helper, because a second copy fails vet with `redeclared`. A command that needs its own exit code returns `exitCode(n)`.
- **[pattern]** Edit Go and specs with a `python3` replace script. Put `assert old in s` on each replacement, or print `MISSING`, so that a stale anchor is not skipped without notice. Replace with count 1. Run `gofmt -l internal cmd` and `go vet` of the touched packages in the same call. Before you write code against a struct from another package, grep its fields. Before you replace a CLAUDE.md layout line, grep it, because the file order in those lines changes between sessions and the anchors go stale.
- **[gotcha]** On the host, `go build ./...`, `go test ./internal/...` and plain `go run ./cmd/automaticum` fail at the link step (`libduckdb_static.a ... undefined reference`), because `internal/store/duck` needs cgo. Never use the `./internal/...` wildcard on the host. Name the packages (`CGO_ENABLED=0 go vet ./internal/daemon ...`, `go test -race ./internal/config ./internal/run ...`) or run `make test`, which picks only the pure-Go packages. `cmd/automaticumd` builds only through `make build`.
- **[pattern]** To find where a number in a spec came from, run `git log --format='%h %ad %s' --date=short -S"<phrase>" -- docs/specs/<file>.md`, then `git show -s --format=%B <hash>`. When the source is another project's code that is not in the repo, mail that project's session (omnimergekit is `backup_models@solidpc`) and ask numbered questions with a proposal for each. Build your own half of the contract, then build the rest from their answers. Record the agreed answer in the spec before you build.
- **[convention]** When you port a rule from another project's code, the spec section must say which parts are theirs, with the file and the commit. It must label automaticum's own parts as its own. Port their logic exactly as written. Defer the parts that belong to another kind of suite to that suite's milestone.
- **[gotcha]** Package-level regexps are not shared across packages. In `internal/config` the name pattern is `armNameRE`. `nameRE` exists only in `internal/task`. Run `grep -n 'regexp.MustCompile' internal/<pkg>/*.go` before you reuse one.
- **[convention]** Daemon state that must survive a restart goes in the `control` struct in `internal/daemon/control.go`, which is saved as `control.json`. A new map needs its nil-map initialisation in both places: after the load and in the fresh literal. Change it under `d.mu`, then call `d.saveControl()`. Anything registered at runtime from that state (for example mode C cell endpoints) must also be re-registered in `loadControl`.
- **[convention]** Never read endpoints with `d.Local.Endpoints[name]` or check lane permission with `lane.Endpoints` directly. Use `Local.Endpoint(name)` and `Local.MayUse(lane, name)`, which also see the endpoints of mode C cells (`cell-<key>`). Code that reloads an arm for a queued run (fly, the canary, afterHeld) must use `d.armFor(batch, name)`. Otherwise a cell's run talks to the arm file's own endpoint.
- **[gotcha]** `internal/daemon` tests run with `-race`. Never read a `*State` from `d.ctl` after `d.mu.Unlock()`. Copy what you need while you hold the lock. Build every API view from a `snapshot()`. To find the racing line, run `grep -A6 'WARNING: DATA RACE\|Previous'` on the output.
- **[pattern]** A daemon test that needs the real arms and tasks uses `newRig`. If it needs its own files, it makes a `t.TempDir()`, symlinks `../../arms` and `../../tasks` into it, and sets `g.d.Repo`. To test a restart, set `g.d.ControlFile` to a temp file, then build `&Daemon{Local: ..., ControlFile: ...}` and call `.init()`. To see what each run was given, record `run.Request`s in `fakeRunner`. For a model server, point `httptest.NewServer(stubmodel.New(...))` at it. Run new tests with `-count=3`.
- **[pattern]** To deploy a rebuilt daemon, run `make build SPIKE_ROOT=<dir>`. Find the pid with `ss -ltnpH 'sport = :7411'`, send it `kill -TERM`, and poll `kill -0` until it is gone. Then run `nohup ./bin/automaticumd --config $AUTOMATICUM_CONFIG >> <work>/automaticumd.log 2>&1 &`, and poll `curl -sf http://127.0.0.1:7411/v1/status` until it answers. Check `automaticum status` first to make sure nothing is in flight.
- **[env]** Foreground `sleep` is blocked in this environment. Inside a polling loop, wait with `timeout 1 tail -f /dev/null`, and bound the loop with `for i in $(seq 1 N)`.
- **[gotcha]** The Caliber pre-commit hook runs on every `git commit`. Stage with `git add -A . ':!.wolf/cron-state.json'`. Before you commit, run the public-repo name scan over `git ls-files`, leaving out `CALIBER_LEARNINGS.md` and `package-lock.json`. It must print `CLEAN`.
- **[correction]** When an Ollama or xOllama server can be asked or told something, automaticum asks it or does it itself. It does not ask the owner to do it. The exception is a mode C cell's endpoint: the caller owns it, so automaticum never loads or unloads anything there.
- **[convention]** Detector versions of ingest's own findings live in the `Versions` map in `internal/ingest/analyse.go`. Whenever a detector's output changes, bump its version (for example `WireArmVersion`) and `AnalysisVersion`, then run `automaticum reanalyse`.
- **[gotcha]** A detector that expects an Ollama `options.*` field (for example `num_ctx`) must check the request's protocol with `Request.OpenAI`. OpenAI-compatible chat (llama-server, vLLM) has no per-request context field. Without the check, every mode C run gets `stated_not_sent` warnings. Ingest maps OpenAI body fields to Ollama option names (`max_tokens` → `num_predict`, `reasoning_effort` → `think`).
- **[pattern]** After any change to ingest, deploy the daemon and run `automaticum reanalyse`, limited with `--run <id>` or `--batch <b>` if needed. Until runs are analysed again, `compare` and `basis` show a missing metric as `UNVERIFIED` or `not recorded: ...`.
- **[gotcha]** Read a finished run's wire capture with `timeout 60 ./bin/automaticum logs <id> --wire`, or with `curl -s http://127.0.0.1:7411/v1/runs/<id>/blobs/wire`. Don't guess a path under the work directory: the runs directory is not `<work>/runs`. Leave out the `*_body` and `*_headers` fields when you print.
- **[gotcha]** `automaticum run tail <id>` never ends. Capture it bounded, to a file on persistent disk: `timeout 8 ./bin/automaticum run tail <id> > <work>/tail.jsonl; true`. Read the runner's notes with `automaticum logs <id>`.
- **[pattern]** To test end to end without a GPU, use the stub model server. The `stub` endpoint in the local config points at the Docker bridge gateway. The stub also speaks llama-server's API (`/v1/chat/completions` with SSE, `/v1/models`, `/props`). To test mode C, run `automaticum stub serve --script <file> --listen 172.17.0.1:7412`, then `automaticum cell run --suite demo:answer --arm stub -n 2 --out <dir> --idempotency-key <k> --endpoint-url http://172.17.0.1:7412/v1 --served-model stub:latest --caller-values <file> --basis-facts '<json>'`. Use a new key for each attempt, and stop the stub afterwards.
- **[gotcha]** On an OpenAI-compatible provider, an arm or caller values with thinking owner `"tag"` make the SDK send its own `thinking.budgetTokens = 1024`, and every run is `INVALID`. Mode C caller values must state `thinking` (`owner = "arm"`, enabled, effort).
- **[gotcha]** llama-server's `GET /props` is at the server root, not under `/v1`: strip `/v1` from the base URL. `default_generation_settings.n_ctx` is the context of one slot, `total_slots` is `-np`, and `build_info` is `b<number>-<commit>`. The context of a slot is not always `-c` divided by `-np` (unified KV cache), so never derive one from the other. vLLM returns 404, so treat 404 as "cannot check".
- **[gotcha]** `.wolf/anatomy.md` lists files under `## <dir>/` sections, and file names repeat across sections (`cell.go` is in both `internal/config/` and `internal/daemon/`). A global regex replace on a file name fails or hits the wrong entry. Edit by walking the lines and tracking the current `## ` section.
